# Unified Typography（统一排版）

[English](README.md) | **简体中文**

**Obsidian** 统一排版控制插件。一套设置同时驱动**编辑模式**（实时预览 + 源码模式）**和阅读模式**，让笔记在哪里看、在哪里改都长一个样。

无需构建——`main.js` 是纯 JavaScript。

## 2.0.0 版更新说明

2.0.0 版本**完全重构**了插件：

- 所有数值均支持 **`px` 与 `em` 两种单位**，任一滑块随时可切换。
- 除正文和各级标题外，新增**列表**（有序 / 无序，分开设置）、**引用块**、**代码块**、**表格**、**分割线**、**Callout**、**数学块**、**嵌入内容**的间距调节。
- 全新设置页：带实时数值显示的滑块、可选项的开关、一键恢复默认值；Obsidian 1.13+ 下所有设置支持在设置搜索中检索。

## 功能

### 通用
- **行高** — 正文行高（无单位倍数，两种模式）。
- **段落间距** — 段落之间的空隙。阅读模式下是段落外边距；编辑模式下是空行高度，因此两种模式显示完全一致的间距。

### 标题（H1–H6）
- 上方 / 下方间距（两种模式）。
- 每级可选字号、字重，通过 Obsidian 的 `--hN-size` / `--hN-weight` 变量驱动，与主题保持同步。
- 编辑模式下紧贴标题下方的空行会被折叠，标题的"下方间距"即为完整间距——与阅读模式一致。

### 列表（有序、无序、任务列表）
- 整个列表的上方 / 下方间距，**有序与无序分开设置**（两种模式）。
- 条目间距（两种模式，通过 Obsidian 的 `--list-spacing` 变量）。
- 单个条目内段落之间的间距。
- 可选的每级缩进（两种模式，`--list-indent`）与条目内行高。

### 其他元素
- **引用块** — 上方/下方间距、内部段落间距。
- **代码块** — 上方/下方间距（两种模式）、可选内部行高（两种模式）。
- **表格** — 上方/下方间距、可选单元格纵向内边距、可选行高（`--table-line-height`）。
- **分割线** — 上方/下方间距（两种模式）。
- **Callout** — 上方/下方间距（阅读模式；编辑模式下未聚焦时生效）。
- **数学块**（`$$…$$`）— 上方/下方间距（两种模式）。
- **嵌入内容**（块引用转置 `![[笔记]]`）— 上方/下方间距。

### 其他
- 总开关 + 独立的 *应用于阅读模式* / *应用于编辑模式* 开关。
- 一键 **恢复默认值**。
- 所有长度值均支持 **`px` 或 `em`**，逐项自由选择。

## 工作原理

插件读取设置后生成一份 CSS 样式表注入应用。凡 Obsidian 已提供排版 CSS 变量的地方（`--line-height-normal`、`--p-spacing`、`--list-spacing`、`--list-indent`、`--hN-size`、`--hN-weight`、`--table-line-height` 等），插件直接设置变量，使编辑模式、阅读模式、渲染嵌入、悬浮预览和画布卡片保持一致且对主题友好；没有变量的地方则对 `.markdown-rendered`（阅读）和 `.markdown-source-view.mod-cm6` / `HyperMD-*` 行类（编辑）输出定向规则。

编辑模式的间距通过 CodeMirror 行的内边距（`HyperMD-header-N`、`HyperMD-codeblock-begin/end`、`HyperMD-hr` 等）以及空行高度实现，空行检测使用与 Obsidian 相同的 `:has(> br:only-child)` 选择器。

## 安装

### 从 GitHub 安装
1. 从 [最新 Release](https://github.com/tychoon/unified-typography/releases) 下载 `main.js`、`styles.css` 和 `manifest.json`。
2. 复制到 `<仓库>/.obsidian/plugins/unified-typography/`。
3. 重启 Obsidian（或在不保存的情况下重载）。
4. 打开 **设置 → 第三方插件**，启用 **Unified Typography**。

### 从源码手动安装
将本仓库的 `manifest.json`、`main.js` 和 `styles.css` 复制到
`<仓库>/.obsidian/plugins/unified-typography/` 即可——无需构建。

所有配置都在 **设置 → Unified Typography** 中。

## 关于两种模式的说明

Obsidian 的**阅读模式**渲染为静态 HTML，**编辑模式**基于 CodeMirror 6——表格、Callout、嵌入等实时块在其中以嵌入组件的形式呈现。两条渲染管线的 DOM 结构与排版机制不同，插件虽已尽可能对齐排版，但**部分嵌入元素在两种模式之间难免存在细微差异**。如果某个差异影响了你，欢迎反馈（见下）——带具体例子的反馈有助于继续改进对齐规则。

## 反馈

发现两种模式间的间距不一致或其他问题？请在
[GitHub](https://github.com/tychoon/unified-typography/issues)
提交 issue——**附上阅读模式与编辑模式并排对比的截图**能大幅加快定位。也欢迎功能建议和 Pull Request。

## 兼容性

- 需要 Obsidian **1.5.0+**（使用 CSS `:has()`，Obsidian 1.2 起可用）。
- Obsidian **1.13+** 下设置页以声明式渲染，所有设置可在 Obsidian 设置搜索中检索；旧版本自动回退到相同界面。
- 兼容大多数主题；生成的规则带 `!important`，优先级高于主题默认值。关闭总开关可与主题原生效果对比。
